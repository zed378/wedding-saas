## What changed

Dates now read **15 Mei 2027** on the invitation's cover, on every event card, in the link-preview
description a WhatsApp card shows, and on the dashboard's invitation cards. Before, the public page
printed `2027-05-15`.

## Why

`OQ-27`'s format half, answered by the owner. `OQ-27` is now fully answered (ADR-070, ADR-072).

## How

`formatEventDate` in `@wi/schema/invitation/event-date.ts`: a strict `YYYY-MM-DD` match, a
calendar check (month range, days in month, leap years), and a twelve-name month table. Exported on
a dependency-free subpath (`@wi/schema/event-date`) for the renderer's client components and from
the package root elsewhere. `HeroClassic` and `EventCardDouble` wrap it in `<time datetime>`;
`metadata.ts` uses it in the description; `InvitationCard` replaces its own `Intl` formatter with it.

## Decisions Made

ADR-072: the format; one formatter; a table instead of `Intl` (server/browser ICU differences would
break hydration); ISO kept for machines; invalid values shown unchanged.

## Deviations from `docs/`

`docs/UI-UX/14` amended to state the format.

## What Did Not Work

- **The visual baselines did not fail** on the date change: the text is under the suite's 1% pixel
  tolerance. `--update-snapshots` also skipped them, because Playwright's default mode only rewrites
  failing snapshots; `--update-snapshots=all` rewrote exactly the four affected images, reviewed by
  eye. The tolerance is too loose to catch a text change in a section — worth tightening per
  section in a later pass.
