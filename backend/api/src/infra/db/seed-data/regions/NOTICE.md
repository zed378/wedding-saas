# Region data — source and licence

The files in this directory (`regions.tsv`, `regions-level-1-2.json`, `boundaries.json`) are generated by `import-regions.mts` from:

- **Repository**: https://github.com/cahyadsn/wilayah
- **Commit**: `686c3400caa75bd7de6a7ac107af073897276133` (2026-09-11)
- **Files**: `db/wilayah.sql` (codes and names, all four levels) and `db/wilayah_level_1_2.sql` (capital, coordinates, UTC offset and boundaries for provinces and regencies)
- **Legal basis cited by both files**: Kepmendagri No. 300.2.2-2138 Tahun 2025 on the codes and data of government administrative regions. The repository description cites No. 300.2.2-2430 Tahun 2025.
- **Retrieved**: 2026-09-13, by `P2-17`

**Changes made**: boundaries simplified (Douglas-Peucker, 0.0005 degrees, about 55 m), coordinates stored as longitude/latitude with five decimals, the UTC offset translated to an IANA zone name, and the SQL converted to the files above. Verified counts: 38 provinces, 514 regencies/cities, 7,285 districts, 83,762 villages.
